# Generating name tags in an automated way

Python script I wrote in the context of organizing a scientific conference (D-LOCKS, 2023): it turns the registration form export into everything the organisers need on paper. 

I have used the free version of Claude to generate an anonymous list of people. The real data was exported from an Excel sheet into a CVS format and then read in Python. Everything here runs on a fully synthetic dataset (data/sample_registrations.csv, generated by generate_sample_data.py).

| Description of the Notebooks |

01_randomise_abstracts.ipynb: Selects the abstracts, shuffles them with a fixed seed, and writes an anonymous PDF for blind review plus a key PDF with the authors for the organisers. 

02_participant_list.ipynb: Builds the participant list with career level, affiliation and dietary requirements/allergies for the catering.

03_create_nametags.ipynb: Draws a name tag per participant on a template (one per page, and A3 sheets of 5 x 4 tags ready to print such that they have the right size to be printed and cutout. 



## Run it
pip install -r requirements.txt
