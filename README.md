# D-LOCKS conference generating name tags in an automated way

Python script I wrote in the context of organizing a scientific conference (D-LOCKS, 2023): it turns the registration form export into everything the organisers need on paper.

I have used the free version of Claude to generate an anonymous list of people. The real data was exported from an Excel sheet into a CVS format and then read in Python.

| Description of the Notebooks |
|---|---|
| `01_randomise_abstracts` | Selects the oral-presentation abstracts, shuffles them with a fixed seed, and writes an **anonymous** PDF for blind review plus a key PDF with the authors for the organisers. |
| `02_participant_list` | Builds the participant list with career level, affiliation and dietary requirements/allergies for the catering. |
| `03_create_nametags` | Draws a name tag per participant on a template (one per page, and A3 sheets of 5 x 4 tags ready to print). |

![Example name tag](examples/name_tag_example.png)

More examples are in [`examples/`](examples).

## Privacy
The real registration data (names, e-mails, dietary needs, abstracts, review scores) is **not** part of this repository. Everything here runs on a **fully synthetic** dataset (`data/sample_registrations.csv`, generated by `generate_sample_data.py`): invented people, `example.org` addresses and placeholder abstracts. Generated files go to `output/`, which is git-ignored.

## Run it
```
pip install -r requirements.txt
cd notebooks
jupyter notebook
```
To use it for an event of your own, export your registration form to CSV with the same columns as the sample (`Name`, `Email address`, `Department`, `Career level`, `Would you like to give an oral presentation?`, `Title`, `Abstract`, `Dietary requirement`, ...), put it outside the repo (or in `data/private/`) and change `DATA` at the top of each notebook. (`Tidsstempel` is the Danish "timestamp" column of Google Forms.)
